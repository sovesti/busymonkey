# Busy Monkey

### *Ваша защита от бесполезных метрик*

<img src="busymonkey.jpg" width="300" alt="Изображение получено 11.09.26 с https://images.meme-arsenal.com/15e2317cb048784fe5fa8afa7b856b51.jpg">

Наверное, в любом месте, где работает достаточно много людей, менеджеры пытаются придумать для сотрудников KPI. Трудно сказать, бывает ли от этого какая-то польза, но вреда "объективные" метрики точно принесли немало.

Один из таких показателей - время, проведённое сотрудником за компьютером. Когда можно собрать слепую статистику и по ней оценить всех сразу, такие мелочи, как общение, размышления и перерывы не у монитора отходят на второй план. Наш инструмент нужен, чтобы загладить эту несправедливость незаметно для Вашего работодателя.

## Особенности

- Генерация активности мышки и клавиатуры
- Тонкая настройка параметров
- Удобный интерфейс
- Горячие клавиши
- Активность по записанному шаблону
- Не обнаруживается трекерами активности
- Маскировка приложения в списке процессов
- Активность в браузере
- Выключается, как только Вы возвращаетесь к работе
- Перенос настроек на другое устройство
- Кросс-платформенность
- Мы не собираем данные о Вас
