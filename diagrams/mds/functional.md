# Busy Monkey — функциональные требования

STAGE 2 — базовый MVP на Windows 11 x64; этапы 3–5 — функциональность после MVP. 

Поддержку Windows 10, Linux и macOS проверяют на этапе 5.

## Функциональные требования

| ID    | Этап roadmap             | Требование и критерий приёмки                                                                                                                                                                             |
| ----- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-01 | 2 / MVP                  | Пользователь может записать собственные действия в качестве шаблона. Чувствительные данные не записываются.                                                                                               |
| FR-02 | 2 / MVP                  | Пользователь запускает базовый сценарий кнопкой либо настраиваемой горячей клавишей; используются выбранные параметры.                                                                                    |
| FR-03 | 2 / MVP; расширение 4    | Пользователь останавливает сценарий кнопкой или горячей клавишей. После завершения остановки новые события не создаются.                                                                                  |
| FR-04 | 2 / MVP                  | В MVP интерфейс показывает «Остановлен», «Работает», «Ошибка», оставшееся время и понятное сообщение об ошибке.                                                                                           |
| FR-05 | 2 / MVP                  | По окончании заданной длительности сценарий завершается без действия пользователя. Показывается причина остановки «Таймер».                                                                               |
| FR-06 | 2 / MVP                  | Параметры сценария сохраняются локально и восстанавливаются после перезапуска.                                                                                                                            |
| FR-07 | 2 / MVP                  | Локальный базовый сценарий запускается, выполняется и останавливается без интернета, сервера и авторизации.                                                                                               |
| FR-08 | 4                        | При обнаружении реального физического ввода пользователя сценарий **приостанавливается**, а не завершается                                                                                                |
| FR-09 | 3                        | Пользователь создаёт, выбирает, переименовывает и удаляет именованные профили параметров.                                                                                                                 |
| FR-10 | 3                        | Пользователь видит лог сеансов: время начала, длительность, профиль и причину остановки.                                                                                                                  |
| FR-11 | 3                        | Пользователь явно запускает и останавливает запись типов действий, после чего может воспроизвести результат как шаблон.                                                                                   |
| FR-12 | 2 / MVP                  | Пользователь выбирает разрешённые клавиатурные действия, задаёт их интервалы и может включить/выключить их отдельно от перемещения мыши.                                                                  |
| FR-13 | 3                        | Пользователь выбирает шаблон и проверяет его перед запуском. Неверный формат и недопустимые действия приводят к сообщению, исполнение не начинается.                                                      |
| FR-14 | 3–4                      | Пользователь может вручную приостановить и возобновить сценарий, пауза не генерирует действий, ошибка не ложит приложение и отображается в UI. На этапе 4 добавляется автоматическое управление по FR-08. |
| FR-15 | 5                        | Пользователь может включить браузерную интеграцию                                                                                                                                                         |
| FR-16 | 3 (шаблоны), 5 (перенос) | Пользователь импортирует и экспортирует шаблоны и настройки в документированном формате с номером версии. На этапе 5 проверяется перенос между устройствами.                                              |


## Трассировка на roadmap

- **STAGE 2:** FR-01–FR-07, FR-12 — окно, генерация ввода, параметры, горячие клавиши, локальное сохранение.
- **STAGE 3:** FR-09, FR-11, FR-13, FR-14, FR-16 (импорт/экспорт шаблонов).
- **STAGE 4:** FR-08, расширение FR-03 и FR-14 — ввод пользователя, пауза и экстренная остановка.
- **STAGE 5:** FR-15 и перенос настроек по FR-16; проверка платформ относится к NFR-07.
- **Вне текущей roadmap:** FR-10 — локальная история; согласовать приоритет отдельно.
