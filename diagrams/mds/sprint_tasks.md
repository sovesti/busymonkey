# Busy Monkey - задачи по sprintам

sprintы соответствуют этапам roadmap. sprint 2 - MVP на Windows 11 x64, sprintы 3-5 - развитие, sprint 6 - проверка перед релизом. Роли указаны по задачам, один человек может совмещать несколько ролей.

## sprint 1. Аналитика и проектирование

| Роль        | Задача                                                                                                 | ФТ / НФТ                   |
| ----------- | ------------------------------------------------------------------------------------------------------ | -------------------------- |
| Analytics, PM | Сравнить 7 систем мониторинга, собрать матрицу функций и зафиксировать требования.                     | FR-01–FR-16, NFR-01–NFR-11 |
| Windows, UI, Backend | Выбрать ОС, язык и UI-фреймворк, разделить интерфейс, сценарии и хранение данных.                      | FR-02–FR-07, NFR-07        |
| DevOps | Зафиксировать версии инструментов и зависимостей, описать сборку.                                      | NFR-08                     |
| QA, Windows | Подготовить проверки и стенд: Windows 11 x64, от 4 логических процессоров и 8 ГБ RAM, экран 1920×1080. | NFR-01–NFR-04, NFR-07      |
