# Busy Monkey — нефункциональные требования

## Нефункциональные требования

| ID     | Категория                         | Критерий приёмки и способ проверки                                                                                               |
| ------ | --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| NFR-01 | Отзывчивость (2, 4)               | Для FR-08 отдельно измеряется задержка реакции на физический ввод.                                                               |
| NFR-02 | Надёжность (2–6)                  | 10 сеансов по 2 часа без сбоев. Повторный запуск не дублирует сценарий, закрытие приложения прекращает ввод.                     |
| NFR-03 | Производительность (2, 6)         | Средняя загрузка CPU ≤ 2% за 10 минут. Рост потребления памяти за 2 часа (после первых 5 минут) ≤ 10 МБ.                         |
| NFR-04 | Удобство (2, 6)                   | 9 из 10 новых пользователей самостоятельно настраивают, запускают и останавливают сценарий. Первый запуск — не дольше 60 секунд. |
| NFR-05 | Приватность (3, 5, 6)             | Данные хранятся локально и не передаются без согласия. Логирование включается вручную                                            |
| NFR-06 | Безопасность (2–6)                | Ошибки разрешений и API не вызывают сбоев, секреты не попадают в логи. HTTPS и безопасное хранение паролей                       |
| NFR-07 | Совместимость ОС (2, 5)           | MVP — Windows 11 x64. Далее — Windows 10, Linux и macOS                                                                          |
| NFR-08 | Воспроизводимость сборки (1–6)    | Проект собирается на чистом окружении по инструкции с зафиксированными версиями инструментов и зависимостей.                     |
| NFR-09 | Совместимость браузера (5)        | Поддерживаемые браузеры и версии определяются до FR-15. Сценарии тестируются в каждом из них.                                    |
| NFR-10 | Переносимость конфигураций (3, 5) | Настройки экспортируются и восстанавливаются на другом устройстве. Повреждённый файл не изменяет текущие настройки.              |
| NFR-11 | Безопасное выполнение (3–6)       | При паузе, остановке или закрытии приложения генерация ввода прекращается. Ошибки не оставляют активных фоновых сценариев.       |

## Стенд и границы измерений

- **Базовый стенд MVP:** Windows 11 x64, >= 4 логических процессоров, >= 8 ГБ RAM, экран 1920×1080.
- Перед измерениями фиксируются конкретные CPU, ОС, объём RAM и сборка программы; результаты разных стендов не сравниваются напрямую.
- Маскировка процесса и обещания необнаружимости в системах мониторинга не включены как гарантии. Статистика (если добавлена) описывает сеансы работы приложения, а не продуктивность сотрудника.
